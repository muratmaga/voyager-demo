# Voyager demo

Smithsonian Voyager Explorer showing two phytolith meshes (Strömberg lab, UW), served from GitHub Pages.

- https://muratmaga.github.io/voyager-demo/ — Aira caryophylla
- https://muratmaga.github.io/voyager-demo/anomochloa.html — Anomochloa marantoidea

The page is one `<voyager-explorer>` element pointing at `models/`, as in
https://dpo.si.edu/blog/hosting-your-own-interactive-3d-web-experiences-smithsonian-voyager-platform
